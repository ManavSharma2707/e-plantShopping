# Paradise Nursery – e-plantShopping

Paradise Nursery is a houseplant shopping app. Browse plants by category, add them to a cart, and manage quantities on a dedicated cart page. Built with React and Redux Toolkit.

## Features

- Landing page with a background image, company description, and a "Get Started" button
- Product listing with 3 categories (Air Purifying, Aromatic, Medicinal), 6 plants each
- Redux-powered shopping cart (add, remove, update quantity)
- Navbar with Home / Plants / Cart links and a live cart-count badge
- Cart page with +/- quantity controls, per-item totals, total plant count, total amount, Delete, Continue Shopping, and Checkout ("Coming Soon")

## Tech Stack

- React
- Redux Toolkit (react-redux)
- Vite

## Run Locally

```bash
npm install
npm run dev
```

## Deploy (GitHub Pages)

```bash
npm run deploy
```

Then in the repository go to Settings > Pages and confirm the source is the `gh-pages` branch (root).
